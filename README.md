# MusicDownloader

**MusicDownloader** — настольное приложение для Windows на C# и WPF, предназначенное для скачивания музыкальных треков. Проект развивается как единый загрузчик с возможностью постепенно добавлять новые музыкальные источники.

На текущем этапе реализована интеграция с **ВКонтакте (VK)**.

## Возможности

- Работа с музыкой ВКонтакте.
- Скачивание треков на компьютер.
- Параллельная загрузка нескольких файлов.
- Настройка доступа к VK через отдельный компонент для хранения токена.

## Технологии

- C#
- .NET / WPF
- Dependency Injection
- `HttpClient`

## Архитектура

Логика работы с источниками музыки вынесена в отдельные компоненты. Это позволяет развивать приложение и добавлять новые интеграции, не смешивая код разных сервисов.

Основные компоненты текущей реализации:

- `VkMusicDownloader` — реализация загрузчика для ВКонтакте.
- `VkTokenStorage` — компонент для работы с токеном VK.
- `VkServices` — регистрация и настройка сервисов, связанных с VK.
- `IMusicDownloader` — контракт загрузчика.

Зависимости приложения настраиваются через Dependency Injection.

## Запуск

1. Склонируйте репозиторий.
2. Откройте solution-файл проекта в Visual Studio.
3. Восстановите NuGet-зависимости.
4. Настройте необходимые данные для доступа к VK.
5. Соберите и запустите WPF-приложение.

> Для запуска требуется Windows, поскольку интерфейс приложения построен на WPF.

## Важно

Используйте приложение только для загрузки материалов, на которые у вас есть необходимые права или разрешение. Пользователь самостоятельно отвечает за соблюдение законодательства и правил используемых сервисов.
